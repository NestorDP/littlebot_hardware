Littlebot Hardware Documentation
================================

Welcome to the technical documentation of the Littlebot Hardware project.

This repository contains the electronic and physical hardware design
resources for the Littlebot differential-drive robot.

The documentation describes the hardware requirements, design architecture,
electrical and mechanical implementation, and hardware development process.
